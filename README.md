# Music-Data-Generator
Input your favorite song and look up its details!

Below is a short tutorial on how to use the app:


https://github.com/user-attachments/assets/39ea4f41-f58a-4132-aae2-7ed5f2e3d067



This local Music Data Generator app employs Spotify's API to gather song data. It is made up of 4 fully independent microservices that communicate with each other via text files. To use the app, start each of the .py files in their own terminals. 

The song_input_service.py file is the UI. Follow the instructions displayed on the screen after it is run, and when you are done, read through all the information on your song!
